THE SHORT VERSION

Draw. Guess. Climb.

  1. Create a room and share its code with 1–7 friends.
  2. The host starts. Take turns drawing a secret word in 60 seconds. No letters, numbers, or saying the answer!
  3. Everyone else guesses. First correct guess earns 100 points, second 75, and later guesses 50 each.
  4. The artist earns 25 points for each correct guess when the round ends.
  5. Climb a floor every 150 points. At round end, a player with 600 points wins; highest score wins if several qualify. Ties go to the player who joined first.

All drawing tools are available to everyone. Join before a game starts. A disconnected player leaves the game; rejoin in the lobby or after a rematch. If the artist leaves, the round ends. The next player becomes host if the host leaves.
