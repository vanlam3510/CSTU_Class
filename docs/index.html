AI Finance: Student Quickstart Setup

A step-by-step beginner guide to getting your development environment ready.

Before You Begin: Where do I type these commands?
  • Windows users: Open the Start Menu, search for PowerShell or Command Prompt, and hit Enter.
  • Mac users: Press Cmd + Space, type Terminal, and hit Enter.
1
Install Git
In plain English: Git is a download and version-tracking tool. It lets you pull down class code directly to your computer.

1. Download the installer for your computer:

Download Git Official Installer →

2. Run the downloaded installer. You can keep all default options selected.

3. Verify installation by typing this into your terminal:

git --version
2
Install Python 3.10+
In plain English: Python is the programming language engine that executes our financial AI programs.

1. Download the official installer:

Download Python (python.org) →
Important Windows Step: On the very first installation screen, you MUST check the box that says "Add Python to PATH" before clicking "Install Now".

Verify installation:

python --version

(Mac users might need to type python3 --version)

3
Download the Course Project
In plain English: We use Git to grab the project files from GitHub and place them into a folder on your computer.

Run these two commands one by one:

git clone https://github.com/aaron-recompile/AI_Finance.git cd AI_Finance
4
Create and Activate a Virtual Environment
In plain English: Think of a virtual environment like a private toolbox created just for this class. Anything we install here stays organized inside this folder without cluttering the rest of your computer.

1. Create the environment folder named venv:

python -m venv venv

2. Activate it:

venv\Scripts\activate

Success check: You will see (venv) appear at the very start of your terminal prompt line.

1. Create the environment folder named venv:

python3 -m venv venv

2. Activate it:

source venv/bin/activate

Success check: You will see (venv) appear at the very start of your terminal prompt line.

5
Install Required Packages
In plain English: requirements.txt is a shopping list of all the financial and AI libraries the project needs. This command downloads and installs them all automatically.

Run the install command (ensure (venv) is active):

pip install -r requirements.txt

This may take 1 to 3 minutes depending on your internet connection.

6
Run Scripts & Save Output to a File
In plain English: When you run a script, it generates links, addresses, or output tables. By adding | tee output.txt or > output.txt, your computer displays the results on screen and saves a permanent copy to a text file so you can review it later.

In Windows PowerShell, run your script and pipe to Tee-Object:

python main.py | Tee-Object -FilePath "server_info.txt"

To view your saved output file later:

type server_info.txt

In macOS Terminal, run your script and pipe to tee:

python3 main.py | tee server_info.txt

To view your saved output file later:

cat server_info.txt
